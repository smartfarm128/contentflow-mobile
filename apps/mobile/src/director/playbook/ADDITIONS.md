# Additions to Paul Funchious's playbook

These are rules the app had to invent so the playbook could run inside ContentFlow. They are not part of `paul-playbook.md`. That file is unchanged. Date: 2026-10-13.

## Add to §2, rule 2

The app cannot cut a person matte. It moves captions and titles to a clear band (top, centre, or bottom). If every band still touches a face, it uses the band that overlaps least and says the text is not fully clear.

If face detection cannot run, the text stays where it was placed and the Director says faces were not checked.

## Add to §2, rule 5

The app has no official logo files. A request that names a logo is refused. Plain text of a brand name, with no logo, is allowed.

## Add to §2, rule 6

The app has no avatar or face generator. A request to create a likeness, including Paul's, is refused. It will not invent a substitute face. Unnamed stock footage of a person at work is not a likeness.

## Add to §9

Titles the Director adds use lime `#D8F34A`. The words don't, do not, never, warning, stop, and avoid use red `#FF3B30`. Caption bodies stay white. The spoken-word highlight the Director sets is lime. The manual text button is still white.

## Add to §10

In the app, a portrait canvas (taller than it is wide, including 9:16 and 4:5) is a reel for the no-music-bed rule. Square and landscape are not. Importing an audio file onto a portrait project is refused. The short bundled sounds stay available as effects. The app cannot fetch a trending sound or a licensed bed.
